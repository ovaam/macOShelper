# Описание проекта: macOShelper

## 1. Общая информация

**Название проекта:** macOShelper  
**Тип проекта:** Настольное приложение для macOS  
**Язык программирования:** Swift  
**Фреймворк:** SwiftUI, AppKit  
**Дата создания:** 04.02.2026  
**Автор:** Малова Олеся

## 2. Описание проекта

macOShelper — это комплексное приложение для повышения продуктивности работы на macOS, объединяющее в себе несколько инструментов для управления задачами, временем, буфером обмена и быстрого доступа к приложениям и файлам. Приложение разработано с использованием современных технологий Apple и предоставляет пользователю единый интерфейс для решения повседневных задач.

## 3. Цели и задачи проекта

### Основные цели:
- Создание универсального инструмента для повышения продуктивности работы на macOS
- Объединение нескольких полезных функций в одном приложении
- Обеспечение быстрого доступа к часто используемым функциям через глобальные горячие клавиши
- Улучшение организации рабочего процесса пользователя

### Задачи:
1. Реализация системы управления задачами с приоритетами, тегами и сроками выполнения
2. Разработка таймера Pomodoro с интеграцией системы фокусирования macOS
3. Создание истории буфера обмена с возможностью назначения горячих клавиш
4. Реализация быстрого лаунчера для поиска и запуска приложений и файлов
5. Обеспечение удобного пользовательского интерфейса с поддержкой темной темы

## 4. Функциональность приложения

### 4.1. Менеджер задач (Task Manager)
- Создание, редактирование и удаление задач
- Установка приоритетов (высокий, средний, низкий)
- Добавление описаний и тегов к задачам
- Установка сроков выполнения (due date)
- Отметка задач как выполненных
- Поиск задач по названию
- Фильтрация задач по приоритету
- Оценка времени выполнения задач (estimated duration)
- Связь задач с таймером Pomodoro

### 4.2. Таймер Pomodoro
- Запуск таймера с настраиваемой длительностью (15, 25, 45 минут или произвольное время)
- Пауза и возобновление работы таймера
- Привязка таймера к конкретной задаче
- Автоматическое включение режима фокусирования macOS при старте
- Автоматическое отключение режима фокусирования при завершении
- Плавающее окно с таймером для отслеживания времени
- Статистика работы:
  - Общее время за сегодня
  - Общее время за последние 7 дней
  - График продуктивности по дням недели
- Уведомления о завершении сессии с мотивирующими сообщениями
- Сохранение истории сессий

### 4.3. История буфера обмена (Clipboard History)
- Автоматическое отслеживание всех копирований в буфер обмена
- Хранение истории до 50 записей
- Поддержка различных типов данных:
  - Текстовые данные
  - Изображения (с превью)
  - Файлы
  - Смешанные типы данных
- Быстрая вставка элементов из истории
- Назначение пользовательских горячих клавиш для быстрого доступа к элементам
- Превью изображений при длительном нажатии
- Автоматическая очистка старых записей при превышении лимита
- Сохранение истории между сеансами работы
- Хранение файлов во временной директории для файловых элементов

### 4.4. Быстрый лаунчер (Quick Launcher)
- Глобальная горячая клавиша для вызова лаунчера (настраиваемая)
- Поиск и запуск приложений:
  - Сканирование приложений в /Applications, /System/Applications, ~/Applications
  - Отображение иконок приложений
  - Умный поиск с ранжированием результатов
- Поиск и открытие файлов:
  - Сканирование Documents, Downloads, Desktop
  - Поддержка различных типов файлов
  - Быстрый доступ к недавно используемым файлам
- Встроенные команды приложения:
  - Создание новой задачи
  - Просмотр задач
  - Запуск Pomodoro (15, 25 минут)
  - Остановка Pomodoro
  - Очистка буфера обмена
  - Переход к различным разделам приложения
- Доступ к истории буфера обмена прямо из лаунчера
- Переключение между режимами поиска и буфера обмена
- Навигация по результатам с клавиатуры (стрелки вверх/вниз)
- Fuzzy search с ранжированием результатов по релевантности
- Группировка результатов по категориям (Действия, Приложения, Файлы)

## 5. Технологии и инструменты

### Основные технологии:
- **Swift 5+** — основной язык программирования
- **SwiftUI** — фреймворк для построения пользовательского интерфейса
- **AppKit** — для работы с системными функциями macOS
- **Combine** — для реактивного программирования
- **UserNotifications** — для отправки уведомлений
- **CoreGraphics** — для работы с графикой
- **Carbon** — для работы с глобальными горячими клавишами
- **ApplicationServices** — для работы с системными разрешениями

### Системные API:
- **NSPasteboard** — для работы с буфером обмена
- **AXIsProcessTrusted** — для проверки разрешений Accessibility
- **CGEvent** — для симуляции нажатий клавиш
- **NSWorkspace** — для запуска приложений и открытия файлов
- **UNUserNotificationCenter** — для уведомлений

### Архитектурные паттерны:
- **MVVM (Model-View-ViewModel)** — для организации кода
- **Singleton** — для сервисов (ClipboardHistoryService, PomodoroService, CommandRegistry)
- **Observer Pattern** — через Combine и NotificationCenter
- **Command Pattern** — для команд лаунчера

## 6. Архитектура приложения

### Структура проекта:

```

│   ├── ClipboardModels.swift
│   ├── PomodoroModels.swift

│   ├── Main/            # Главный экран
│   ├── Task/            # Менеджер задач
│   ├── Time/            # Таймер Pomodoro
│   └── QuickLauncher/   # Быстрый лаунчер
├── Services/            # Бизнес-логика
│   ├── ClipboardHistoryService.swift
│   ├── PomodoroService.swift
│   ├── GlobalHotKeyService.swift
│   ├── ClipboardHotkeyCenter.swift
│   ├── FloatingWindowManager.swift
│   ├── ShortcutCreator.swift
│   └── ShortcutRunner.swift
├── Storage/             # Хранение данных
│   ├── ClipboardStorage.swift
│   ├── ClipboardFileStore.swift
│   └── StatsStorage.swift
└── Utilities/           # Вспомогательные утилиты
    └── Extensions/      # Расширения
```

### Основные компоненты:

#### 6.1. Модели данных
- **Task** — модель задачи с полями: id, title, description, priority, tags, dueDate, isCompleted, estimatedDuration
- **ClipboardItem** — модель элемента буфера обмена с поддержкой различных типов данных
- **PomodoroSession** — модель сессии Pomodoro для статистики
- **RunningPomodoroState** — состояние работающего таймера

#### 6.2. Сервисы
- **ClipboardHistoryService** — управление историей буфера обмена, мониторинг изменений, обработка горячих клавиш
- **PomodoroService** — управление таймером, статистикой, интеграция с режимом фокусирования
- **GlobalHotKeyService** — регистрация и обработка глобальных горячих клавиш
- **CommandRegistry** — реестр команд для быстрого лаунчера, сканирование приложений и файлов
- **FloatingWindowManager** — управление плавающим окном таймера

#### 6.3. Хранилище данных
- **ClipboardStorage** — сохранение и загрузка истории буфера обмена (UserDefaults/JSON)
- **ClipboardFileStore** — управление временными файлами для элементов буфера обмена
- **StatsStorage** — хранение статистики Pomodoro сессий

## 7. Особенности реализации

### 7.1. Работа с буфером обмена
- Периодический опрос буфера обмена (каждые 0.8 секунды) для отслеживания изменений
- Фильтрация пустых строк и дубликатов
- Сохранение всех типов представлений данных (text, image, file, etc.)
- Автоматическое создание превью для изображений
- Хранение файлов во временной директории для файловых элементов

### 7.2. Глобальные горячие клавиши
- Использование Carbon API для регистрации глобальных горячих клавиш
- Требование разрешений Accessibility для работы
- Настраиваемые комбинации клавиш для вызова лаунчера
- Индивидуальные горячие клавиши для элементов буфера обмена
- Автоматическая регистрация при запуске приложения

### 7.3. Интеграция с режимом фокусирования macOS
- Автоматическое создание Shortcuts для включения/выключения режима фокусирования
- Интеграция через приложение "Команды" (Shortcuts)
- Автоматическое включение при старте Pomodoro
- Автоматическое выключение при завершении или остановке

### 7.4. Умный поиск в лаунчере
- Алгоритм ранжирования результатов по релевантности
- Поддержка fuzzy search (нечеткий поиск)
- Учет позиции совпадения в тексте
- Приоритизация приложений над файлами
- Группировка результатов по категориям

### 7.5. Пользовательский интерфейс
- Темная тема по умолчанию
- Кастомные шрифты (HSESans)
- Адаптивный дизайн с использованием NavigationSplitView
- Плавные анимации и переходы
- Hover-эффекты для интерактивных элементов
- Плавающее окно таймера с прозрачным фоном

## 8. Системные требования и разрешения

### Системные требования:
- macOS 12.0 (Monterey) или новее
- Разрешение экрана: поддерживаются все разрешения
- Оперативная память: минимальные требования системы

### Необходимые разрешения:
- **Accessibility** — для работы глобальных горячих клавиш и симуляции нажатий клавиш
- **Notifications** — для отправки уведомлений о завершении Pomodoro сессий
- Доступ к файловой системе для сканирования приложений и файлов
