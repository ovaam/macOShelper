## Шаблон описания проекта к КТ1 для программных проектов

### 1. Основные планы и этапы проекта

#### 1.1 Краткое описание проекта:

**Название проекта:** macOShelper — Приложение для повышения продуктивности

**Цель проекта:** Создать комплексное приложение-помощник для пользователей macOS, объединяющее в себе инструменты для управления задачами, временем, буфером обмена и быстрого доступа к приложениям и файлам.

**Краткое описание задач:** 
- Реализовать систему истории буфера обмена с поддержкой различных типов данных (текст, изображения, файлы) и возможностью назначения горячих клавиш для быстрого доступа
- Создать быстрый лаунчер для поиска и запуска приложений и файлов с умным алгоритмом поиска
- Разработать систему управления задачами с приоритетами, тегами, сроками выполнения и интеграцией с таймером
- Реализовать таймер Pomodoro с автоматической интеграцией режима фокусирования macOS, статистикой работы и визуализацией данных
- Обеспечить единый удобный пользовательский интерфейс с поддержкой темной темы и глобальными горячими клавишами

### 2. Используемый технологический стек и его обоснование

| Технология/Инструмент | Описание | Причины выбора |
|----------------------|----------|----------------|

#### 2.2 Обоснование выбранного технологического стека:

Данный стек технологий был выбран по следующим причинам:

1. **Соответствие курсу обучения**: Основные технологии (Swift, SwiftUI, Xcode) были изучены на курсе «Промышленная iOS-разработка», что обеспечивает понимание и эффективное использование инструментов.

2. **Официальная поддержка Apple**: Все выбранные технологии являются официальными инструментами и фреймворками Apple, что гарантирует их стабильность, актуальность и долгосрочную поддержку.

3. **Оптимальность для задач проекта**: 
   - SwiftUI обеспечивает быструю разработку современного интерфейса с поддержкой темной темы
   - AppKit необходим для глубокой интеграции с системой macOS (буфер обмена, глобальные горячие клавиши, запуск приложений)
   - Combine позволяет эффективно управлять состоянием и обрабатывать асинхронные события (таймер, мониторинг буфера обмена)
   - Carbon API — единственный надежный способ работы с глобальными горячими клавишами

4. **Производительность и надежность**: Swift обеспечивает высокую производительность и безопасность типов, что критично для приложения, работающего в фоновом режиме и обрабатывающего системные события.

5. **Доступность и распространенность**: Все инструменты бесплатны и доступны через официальный App Store или сайт Apple, что делает их наиболее доступными для разработки.

6. **Интеграция с экосистемой macOS**: Выбранные технологии обеспечивают глубокую интеграцию с системными функциями macOS (режим фокусирования, буфер обмена, уведомления), что является ключевым требованием для приложения повышения продуктивности.

### 4. Особые пометки

1. **Системные разрешения**: Приложение требует разрешения Accessibility для работы глобальных горячих клавиш и симуляции нажатий клавиш. При первом запуске пользователю будет предложено предоставить это разрешение.

2. **Интеграция с режимом фокусирования**: Для автоматического включения/выключения режима фокусирования macOS требуется одноразовая настройка через приложение "Команды" (Shortcuts). Приложение автоматически создает необходимые команды и предоставляет инструкции пользователю.

3. **Хранение данных**: 
   - История буфера обмена хранится в UserDefaults в формате JSON
   - Файловые элементы буфера обмена сохраняются во временной директории
   - Статистика Pomodoro сессий хранится в UserDefaults
   - Все данные сохраняются локально на устройстве пользователя

4. **Производительность**: 
   - Мониторинг буфера обмена выполняется с интервалом 0.8 секунды для баланса между отзывчивостью и производительностью
   - История буфера обмена ограничена 50 записями для оптимизации использования памяти
   - Сканирование файлов ограничено 1000 файлами из основных директорий (Documents, Downloads, Desktop)

5. **Совместимость**: Приложение разработано для macOS 12.0 (Monterey) и новее, использует современные API и не поддерживает более старые версии операционной системы.

6. **Безопасность**: Приложение работает только с локальными данными пользователя, не передает информацию в интернет, не требует сетевых разрешений. Все операции с файловой системой ограничены домашней директорией пользователя.
